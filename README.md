# Vue Naive UI Template

TypeScript + Vite + Vue + Naive UI template for SaaS dashboards and media operations consoles.

## Quick Start

```bash
npm install
npm test
npm run build
npm run dev
```

## Structure

```text
src/app/                 Application shell and providers.
src/features/            Vue feature pages and typed models.
src/shared/api/          API client boundaries.
src/shared/config/       Runtime config.
profiles/index.json      Product profile mapping.
docs/ENGINEERING_SPEC.md Engineering rules.
```
