# Vanilla Shoelace Template

TypeScript + Vite + Shoelace Web Components template for framework-light frontend apps.

## Quick Start

```bash
npm install
npm test
npm run build
npm run dev
```

## Structure

```text
src/app/                 DOM rendering and app shell.
src/features/            Feature state and display models.
src/shared/api/          API client boundaries.
src/shared/config/       Runtime config.
profiles/index.json      Product profile mapping.
docs/ENGINEERING_SPEC.md Engineering rules.
```
