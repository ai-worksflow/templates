# React MUI Template

TypeScript + Vite + React + Material UI template for SaaS consoles and polished product dashboards.

## Quick Start

```bash
npm install
npm test
npm run build
npm run dev
```

## Structure

```text
src/app/                 Application shell and theme setup.
src/features/            Feature pages and typed view models.
src/shared/api/          API client boundaries.
src/shared/config/       Environment config.
src/shared/ui/           Shared app components.
profiles/index.json      Product profile mapping.
docs/ENGINEERING_SPEC.md Engineering rules.
```
