# React Ant Design Template

TypeScript + Vite + React + Ant Design template for enterprise-grade admin and operations UI.

## Quick Start

```bash
npm install
npm test
npm run build
npm run dev
```

## Structure

```text
src/app/                 Application shell and UI provider setup.
src/features/            Product features and pages.
src/shared/api/          Typed HTTP client boundaries.
src/shared/config/       Environment and runtime config.
src/shared/ui/           Reusable app-level UI components.
profiles/index.json      Product profile mapping for this UI stack.
docs/ENGINEERING_SPEC.md Engineering rules for React + Ant Design.
```
