# Vue Element Plus Template

TypeScript + Vite + Vue + Element Plus template for admin systems and enterprise forms.

## Quick Start

```bash
npm install
npm test
npm run build
npm run dev
```

## Structure

```text
src/app/                 Application shell.
src/features/            Vue feature pages and typed models.
src/shared/api/          API client boundaries.
src/shared/config/       Runtime config.
profiles/index.json      Product profile mapping.
docs/ENGINEERING_SPEC.md Engineering rules.
```
